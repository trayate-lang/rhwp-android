# 상용구 구현 기준 조사

2026-09-13. 아래 공식 동작을 참고하여 0.1.1 시험판을 구현했다. 공식 한글의 모든 개체 보존을 구현한 버전은 아니다.

## 시험 구현 결과

기기 내 IndexedDB에 준말·글자 또는 HTML을 저장한다. 다른 문서에서 글자, 굵게 서식, 2칸 표, 단독 PNG 그림의 등록/실행 왕복을 확인했다. 글자 상용구는 APK 업데이트 후에도 남아 실행됐다. 준말 치환 후 undo/redo도 확인했다.

다른 문서로 전환할 때 원본의 표/그림 선택 상태가 남던 문제, 표 선택을 Alt+i 처리 전에 해제하던 문제, F3 처리기가 Ctrl+F3를 먼저 소비하던 문제를 함께 수정했다.

지원 범위: `README.md`의 0.1.1 안내를 따른다. 표·그림을 포함한 임의의 혼합 문서, 모든 한글 개체, IDO 호환 및 상용구 백업/내보내기는 완성하지 않았다. 등록 데이터 자체는 시스템 클립보드와 별개이며, 삽입은 기존 편집 명령과 스냅샷을 재사용한다.

회귀 실행: 전용 디버그 에뮬레이터에서 `node rhwp-android/scripts/autotext-qa.mjs`. 이 도구는 새 시험 문서를 만들므로 개인 문서에서 실행하지 않는다.

## 확인한 사용자 흐름

- 한컴오피스 2024 한/글 메뉴: 입력 → 입력 도우미 → 상용구.
- 선택 영역에서 Alt+I: 준말과 본말/설명을 지정하여 등록한다.
- 글자 속성 유지: 본문 상용구. 서식과 표·그림을 포함한다.
- 글자 속성 유지하지 않음: 글자 상용구. 글자만 저장한다.
- 표·그림 같은 조판 부호가 포함된 선택은 본문 상용구로 등록한다.
- 선택 없이 준말을 입력한 뒤 Alt+I: 저장한 내용을 삽입한다.
- Ctrl+F3: 상용구 내용 목록. 글자/본문 탭에서 선택하여 넣고 관리한다.

## rHWP Fold에 적용할 화면

입력 메뉴의 상용구 진입점에서 등록, 실행, 상용구 내용을 제공한다.
원본의 긴 계층은 모바일에서 탭 가능한 목록/대화상자로 표현하되 용어는 유지한다.
외장 키보드 없이도 등록과 실행이 가능하도록 메뉴 명령을 단축키와 공유한다.
등록창은 준말, 본말 또는 설명, 글자 속성 유지 여부를 표시한다.
표·그림 포함 시 본문 상용구임을 설명하고 글자 전용 저장은 비활성화한다.

## 구현에서 확인할 점

기존 InputHandler.performCopy는 그림/표 선택에서 WASM copyControl을 호출한다.
이 경로를 재사용하되 시스템 클립보드를 영구 저장소로 사용하지 않는다.
서식 ID와 그림 참조가 원본 문서에 종속되는지 먼저 확인하고 독립 데이터로 보존한다.
등록은 원문을 변경하지 않으며, 실행 시 준말 치환과 삽입을 하나의 실행 취소 단위로 묶는다.
한글 조합 확정, 커서 앞 준말 인식, 중복 준말, 저장 실패를 명시적으로 처리한다.
앱 재실행·다른 문서·오프라인에서 글자, 문단 서식, 표, 그림 각각을 왕복 검증한다.
한컴 IDO 파일 호환은 별도 형식 분석 없이는 지원한다고 표시하지 않는다.
